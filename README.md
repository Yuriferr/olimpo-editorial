# Olimpo — Atlas dos deuses

Projeto desenvolvido com inteligência artificial como teste prático das capacidades básicas do Codex, a ferramenta de programação do ChatGPT. O tema escolhido foi a mitologia grega: um blog editorial estático em português com os doze deuses olímpicos tradicionais, além de um perfil extra para Hades. Cada divindade troca a paleta, a arte de capa, os mitos e o fragmento em destaque. Os cartões abrem leituras em uma janela acessível. Uma seção de perfil apresenta Yuri Fernandes e links para GitHub e LinkedIn.

## Como abrir

Abra `index.html` em um navegador. Não há etapa de compilação nem dependências. As fontes web usam Google Fonts; as fontes de sistema entram como alternativa se estiver offline.

## Arquivos

- `index.html` — estrutura e conteúdo principal
- `styles.css` — identidade visual e layouts responsivos
- `script.js` — troca de divindade, menu móvel e leituras
- `assets/` — treze imagens de capa criadas com IA para este site
